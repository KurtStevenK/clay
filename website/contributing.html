Contributing

Report bugs

Clay is not bug-free. A report with steps, OS, and Clay version helps more than a screenshot alone.

github.com/KurtStevenK/clay/issues

Write code

The program lives in one public GitHub repository. Fork it, branch, open a pull request. Keep existing copyright headers. Clay Design maintains the fork; it does not replace original authors.

github.com/KurtStevenK/clay

Translate

UI strings still live in the po/ gettext files. Send a pull request with your language file. There is no separate Clay translation portal yet. Do not file Clay translation work on GNOME’s l10n site unless you also contribute to upstream GIMP.

This website

Pages are static HTML under website/ and deploy to Firebase Hosting. Edit the page, open a pull request.

Share the program

Give people the installer and this source. Teaching Clay, writing a libre-licensed tutorial, or crediting Clay on a piece of art all count. Money is optional and lives on the donate page.
