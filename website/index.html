CLAY

A free image editor you can change.

Clay is an image beautification program for Windows, Linux, and macOS. It is a fork of the GNU Image Manipulation Program, shared under GPL-3.0-or-later.

Source Docs

Your pictures,
your program.

Retouch a photo, draw, or assemble a layout. Clay keeps the layer, selection, and color tools from the program it forked, with a Clay theme and splash.

Source stays public. If you ship a binary, you offer this source under the same license.

GIMP and the Wilber mascot are names of the upstream project. This fork is Clay. Original authors’ copyright notices stay in the source.
