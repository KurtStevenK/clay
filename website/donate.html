Why money helps

Donating keeps Clay’s hosting, signing, and release work going. It does not buy a different license. The program stays GPL-3.0-or-later.

Not GIMP fundraising

Do not send Clay donations to the GNOME Foundation, ZeMarmot, or GIMP Patreon pages. Those fund the upstream project. If you want to support GIMP itself, use GIMP’s own donate page — separately from Clay.
