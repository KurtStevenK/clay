Documentation

What this page is

Clay’s own notes for install, first launch, and where files live. The full tool-by-tool manual is still the GIMP 3 user manual until Clay writes one.

Clay 3 user manual — menus and tools match Clay closely. Names that still say GIMP in that manual refer to the same actions in Clay.

Install on Windows

The current release is Clay 3.36 for Windows. Get the installer from GitHub Releases. Each release note includes a VirusTotal table for the files we ship.

Run the setup executable. After install, start Clay from the Start menu. Linux and macOS build from the same source; see INSTALL.

First launch

The Welcome window opens on start. Personalize sets the Clay theme, icon size, and font scale. Create opens a new image or a recent file. You can hide Welcome later from that window, or show it again from Help.

F1 opens context help. Until Clay hosts its own manual, that path still follows the GIMP 3 docs linked above.

Theme

Clay ships a Clay theme (light, gray, dark). Pick it under Welcome → Personalize, or later under Edit → Preferences → Theme. Symbolic icons and icon size live on the same page.

Where files live

Clay keeps brushes, palettes, and clayrc in its profile folder:

  • Windows — %APPDATA%\Clay\3.0
  • Linux — ~/.config/Clay/3.0
  • macOS — ~/Library/Application Support/Clay/3.0

Build from source

Desktop builds use Meson. Windows, Linux, and macOS scripts sit under build/ in the repository. Start from INSTALL.
