Tutorials

Open and export a PNG

  1. File → Open, pick a photo.
  2. File → Export As…, type a name ending in .png.
  3. Confirm the PNG dialog. That writes a copy; the Clay project stays as XCF if you save it.

Circle crop

  1. Ellipse Select. Hold Shift while dragging for a circle.
  2. Select → Invert, then Delete, or add a layer mask from the selection.
  3. Export PNG if you need a transparent outside.

Two layers

  1. Open a background. Layer → New Layer for a second sheet.
  2. Paint or paste on the new layer. Move it with the Move tool.
  3. Lower opacity on the Layers dock to fade it. File → Save keeps both layers in XCF.
